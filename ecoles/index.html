02 / PRENDRE DU RECUL

Une carte se lit.
Un parcours se construit.

01

La hauteur donne un repère.

L’axe vertical reprend le « niveau moyen » de l’image. Sa méthode n’est pas fournie : ce n’est ni une note sur 100, ni une probabilité d’admission. Un écart de quelques points doit être interprété avec prudence.

02

La surface représente un effectif.

La légende originale relie la taille des bulles aux intégrés post-CPGE. Une grande bulle ne signifie pas une école meilleure. Les effectifs exacts n’étant pas disponibles, ils ne sont pas inventés dans les fiches.

03

Le programme compte aussi.

Compare les matières, les spécialisations, les projets, les campus et les voies d’admission. Les fiches documentées donnent accès aux pages officielles ; les autres conservent uniquement les repères lisibles sur l’image.

TRANSPARENCE

Des repères, avec leurs sources.

Les positions et logos viennent de l’image d’origine. Les résumés de formation documentés ont été consultés le 28 octobre 2026. Certains anciens noms sont conservés pour retrouver les bulles ; les évolutions connues sont signalées dans les fiches.

Les logos trop petits pour être identifiés avec certitude sont indiqués comme tels. Cette page n’est affiliée à aucune des écoles représentées.
